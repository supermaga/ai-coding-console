## 它能做什么

- **服务总览** —— 纳管服务的在线状态、实时流量、访客与天气，一屏尽收
- **版本时间轴** —— 从 V0.0.0 立项起的每一次改动，全量流水可查
- **访客留言板** —— 来的人都可留一句
- **二次验证** —— 部分敏感入口支持独立口令，逐层设防

## 技术

自研 Web 控制台：Python 标准库后端 + 原生前端，零框架、零构建、零第三方依赖。
Logo 为手绘内联 SVG（六边形外壳 · 内折菱形 · 心跳脉冲 · 轨道光点）。
